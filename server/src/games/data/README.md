# Last Word beta word list

This provisional offline English list was constructed by intersecting the CMU Pronouncing Dictionary word list (CMUDict, BSD-style licensed) with the TextBlob spelling-frequency and English lexicon lists, filtering for alphabetic 4–16 letter terms and basic editorial exclusions. The list is checked into the server: no runtime API calls.

**Editorial review still required before production.** Automated filtering is not a complete proper-noun, offensive-language, or obscure-word filter. The final list and any licensing/attribution requirements must be independently reviewed prior to public launch.

CMUDict: https://github.com/cmusphinx/cmudict
TextBlob: https://textblob.readthedocs.io/
